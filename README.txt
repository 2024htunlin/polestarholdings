POLESTAR HOLDINGS WEBSITE — GITHUB PAGES STARTER

FILES
- index.html
- assets/style.css
- assets/script.js

HOW TO PUBLISH
1. Sign in at https://github.com
2. Create a PUBLIC repository named polestar-website
3. Upload index.html and the assets folder (including both files inside it)
4. Open repository Settings > Pages
5. Under Build and deployment, choose Deploy from a branch
6. Choose branch main and folder /(root), then Save
7. Wait for the Pages deployment and open the URL shown in Settings > Pages

IMPORTANT
- This is a static website starter. GitHub Pages hosting is free for public repositories.
- All repository files and the published website are public. Do not upload confidential documents, passwords, private contact lists, or internal company data.
- Replace sample text, business descriptions, and contact details with company-approved information before public launch.
- The Downloads section is a placeholder. Upload approved documents and add links before using it.
- The sample website uses Google Fonts when internet access is available; system fallback fonts are included.
- Language switching works in the browser and remembers the last selected language on that device.
